# ユーザーストーリー

**INVEST基準準拠**: Independent / Negotiable / Valuable / Estimable / Small / Testable

---

## Epic 1: ユーザー識別・初期設定

### US-01: メールアドレスによるユーザー識別
**As a** 一般ユーザーとして  
**I want** メールアドレスを入力するだけでアプリを使い始めたい  
**So that** アカウント登録の手間なく即座に利用できる

**受け入れ基準**:
- [ ] メールアドレスを入力するとユーザーセッションが開始される
- [ ] 同じメールアドレスで再アクセスすると過去のデータが引き継がれる
- [ ] 無効なメールアドレス形式は入力時にバリデーションエラーを表示する
- [ ] メールアドレスはリクエストヘッダーまたはボディに含まれてAPIに送信される

**ペルソナ**: 田中、佐藤

---

### US-02: データソース連携の権限付与
**As a** 一般ユーザーとして  
**I want** 使いたいデータソース（GitHub・Google Calendar・Slack等）へのアクセスを許可したい  
**So that** システムが自動的に私の行動を取得してチェックポイントを生成してくれる

**受け入れ基準**:
- [ ] 連携可能なデータソース一覧が表示される
- [ ] 各ソースに対してOAuth認可フローが起動できる
- [ ] 認可完了後、連携済みステータスが表示される
- [ ] 連携を解除できる
- [ ] 連携失敗時はエラーメッセージと再試行ボタンが表示される

**ペルソナ**: 田中、佐藤

---

## Epic 2: AIチャット — ユーザーとシステムの対話窓口

AIチャットはユーザーがシステムと対話する唯一の窓口。行動後の振り返り入力と行動前の予定入力の両方を受け付ける。

### US-03: AIとの対話で行動後の振り返りを入力する
**As a** 一般ユーザーとして  
**I want** AIとの対話形式で「今日こんなことをした」と話すように振り返りを入力したい  
**So that** 自然な会話の流れで行動ログを提供でき、システムがチェックポイントを自動生成してくれる

**受け入れ基準**:
- [ ] チャットUIが表示され、AIからの問いかけに答える形で行動後の振り返りを入力できる
- [ ] 会話の流れからシステムがチェックポイントを生成・登録する
- [ ] 会話履歴が表示される
- [ ] 送信後、ダッシュボードのポイントが更新される

**ペルソナ**: 田中、佐藤

---

### US-04: AIとの対話で行動予定を入力する
**As a** 一般ユーザーとして  
**I want** AIとの対話形式で「明日これをやろうと思う」と話すように行動予定を入力したい  
**So that** 予定を立てた行為そのものがポイントとして評価される（「予定を立てた」は偉い）

**受け入れ基準**:
- [ ] チャットUIで行動予定を入力できる
- [ ] 予定の入力自体をシステムがチェックポイントとして生成・登録する（「予定を立てた」行為をポイント化）
- [ ] 予定内容はシステムが将来の達成判定のソースとしても活用できる
- [ ] 送信後、ダッシュボードのポイントが更新される

**ペルソナ**: 田中、佐藤

## Epic 3: データソース連携によるチェックポイント自動生成

### US-06: Google Calendarからチェックポイントが自動生成される
**As a** 一般ユーザーとして  
**I want** Google Calendarのイベントからシステムが自動でチェックポイントを生成してほしい  
**So that** 何もしなくてもカレンダーの行動がポイントに変わる

**受け入れ基準**:
- [ ] Google Calendar連携後、システムが定期的にイベントを取得する
- [ ] イベント参加・作成・更新がチェックポイントとして生成・登録される
- [ ] ユーザーはこのプロセスに関与しない（自動で完結する）
- [ ] 生成されたチェックポイントが達成済みとしてダッシュボードに反映される

**ペルソナ**: 佐藤

---

- [ ] GitHub連携後、システムがWebhookまたはAPIでイベントを取得する
- [ ] コミット・PR作成・Issueコメント等がチェックポイントとして生成・登録される
- [ ] ユーザーはこのプロセスに関与しない
- [ ] 生成されたチェックポイントが達成済みとしてダッシュボードに反映される

**ペルソナ**: 田中

- [ ] 生成されたチェックポイントが達成済みとしてダッシュボードに反映される

## Epic 4: チェックポイント達成判定・ポイント付与

### US-10: システムが自律的に達成判定を行う
**As a** 一般ユーザーとして  
**I want** 何もしなくてもシステムが勝手に達成を判定してポイントを付与してほしい  
**So that** 意識せずにポイントが貯まっていく体験ができる

**受け入れ基準**:
- [ ] ユーザーによる手動チェック操作は存在しない
- [ ] システムがデータソースから取得した情報をもとに達成を自律判定する
- [ ] 達成判定後、即座にポイントが加算される
- [ ] ユーザーは達成前のチェックポイント内容を閲覧できない

**ペルソナ**: 田中、佐藤

---

### US-11: 達成済みチェックポイントのみ閲覧できる
**As a** 一般ユーザーとして  
**I want** 達成したチェックポイントだけを後から確認したい  
**So that** 「こんなことでポイントが貰えたのか」という発見の喜びを体験できる

**受け入れ基準**:
- [ ] 達成済みチェックポイントの一覧が表示される
- [ ] 未達成のチェックポイントは一切表示されない
- [ ] 各チェックポイントに獲得ポイント・達成日時が表示される

**ペルソナ**: 田中、佐藤

---

## Epic 5: ダッシュボード・可視化

### US-12: 累計ポイントを大きく確認できる
**As a** 一般ユーザーとして  
**I want** ダッシュボードを開いたとき最初に累計ポイントが目に入ってほしい  
**So that** 「こんなに貯まった」という達成感を即座に感じられる

**受け入れ基準**:
- [ ] ダッシュボードのメインエリアに累計ポイントが大きく表示される
- [ ] 今日のポイント・週間ポイントも表示される
- [ ] ポイントはリアルタイムで更新される（ページリロード不要）

**ペルソナ**: 田中、佐藤

---

### US-13: 最近達成したチェックポイントを確認できる
**As a** 一般ユーザーとして  
**I want** 最近達成したチェックポイントの一覧をダッシュボードで確認したい  
**So that** 「今日こんなことをした」という記録を振り返れる

**受け入れ基準**:
- [ ] 直近の達成チェックポイントが時系列で表示される
- [ ] 各項目に行動内容・獲得ポイント・達成日時が表示される
- [ ] 新着達成がある場合、ダッシュボードを開いたときにハイライト表示される

**ペルソナ**: 佐藤

---

### US-14: ポイント推移グラフを確認できる
**As a** 一般ユーザーとして  
**I want** ポイントの時系列推移をグラフで確認したい  
**So that** 自分の活動量の変化を視覚的に把握できる

**受け入れ基準**:
- [ ] 日別・週別・月別のポイント推移グラフが表示される
- [ ] グラフの期間を切り替えられる
- [ ] グラフはインタラクティブで、各点にホバーするとポイント数が表示される

**ペルソナ**: 佐藤

## Epic 6: ゲーミフィケーション

### US-15: ポイント蓄積でレベルアップする
**As a** 一般ユーザーとして  
**I want** ポイントが一定量貯まるとレベルアップしてほしい  
**So that** 行動量の少なさを気にせず、些細な積み重ねが形になっていく感覚を得られる

**受け入れ基準**:
- [ ] 現在のレベルと次のレベルまでの進捗がダッシュボードに表示される
- [ ] レベルアップ時に演出（アニメーション等）が表示される
- [ ] レベルに応じた称号・バッジが付与される

**ペルソナ**: 田中、佐藤

---

### US-16: 達成バッジを獲得できる
**As a** 一般ユーザーとして  
**I want** 特定の条件を達成したときにバッジを獲得したい  
**So that** コレクション要素として楽しめる

**受け入れ基準**:
- [ ] 獲得済みバッジの一覧がダッシュボードに表示される
- [ ] バッジ獲得時に演出が表示される
- [ ] 各バッジに獲得条件と獲得日時が表示される

**ペルソナ**: 佐藤

## Epic 7: 管理者機能

### US-17: AIが生成したチェックポイントをレビューできる
**As a** 管理者として  
**I want** AIが生成したチェックポイントの一覧を確認したい  
**So that** 不適切なチェックポイントを早期に発見できる

**受け入れ基準**:
- [ ] 管理者画面でチェックポイント一覧が表示される
- [ ] 生成日時・生成元ソース・ポイント値が表示される
- [ ] フィルタリング・検索ができる

**ペルソナ**: 山田

---

### US-18: 不適切なチェックポイントを削除できる
**As a** 管理者として  
**I want** 不適切なチェックポイントを削除したい  
**So that** ユーザーに不快な体験をさせないようにできる

**受け入れ基準**:
- [ ] チェックポイントを選択して削除できる
- [ ] 削除前に確認ダイアログが表示される
- [ ] 削除後、該当チェックポイントに紐づくポイントも取り消される
- [ ] 削除操作は監査ログに記録される

**ペルソナ**: 山田

---

### US-19: 緊急時にユーザーを削除できる
**As a** 管理者として  
**I want** 問題のあるユーザーを緊急削除したい  
**So that** 不正利用や問題行為に即時対応できる

**受け入れ基準**:
- [ ] 管理者画面でユーザー一覧が表示される
- [ ] ユーザーを選択して削除できる
- [ ] 削除前に確認ダイアログが表示される
- [ ] 削除するとユーザーのデータ（チェックポイント・ポイント履歴）も削除される
- [ ] 削除操作は監査ログに記録される

**ペルソナ**: 山田

---

### US-20: 管理者としてシステムにアクセスできる
**As a** 管理者として  
**I want** 管理者専用の画面にアクセスしたい  
**So that** 一般ユーザーと分離された管理操作ができる

**受け入れ基準**:
- [ ] 管理者用URLまたは認証で管理画面にアクセスできる
- [ ] 一般ユーザーは管理画面にアクセスできない（403エラー）
- [ ] 管理者セッションは適切にタイムアウトする

**ペルソナ**: 山田
