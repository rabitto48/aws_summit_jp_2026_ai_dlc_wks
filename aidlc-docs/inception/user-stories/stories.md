# ユーザーストーリー

**INVEST基準準拠**: Independent / Negotiable / Valuable / Estimable / Small / Testable  
**再設計版**: `So that` 節をテーマ「人をダメにするサービス」に沿った心理的動機に書き直し。依存性・認知の歪み機能のストーリーを追加（US-21〜23）。

---

## Epic 1: ユーザー識別・初期設定

### US-01: メールアドレスによるユーザー識別
**As a** 一般ユーザーとして  
**I want** メールアドレスを入力するだけでアプリを使い始めたい  
**So that** 面倒な登録手続きで「やっぱりやめよう」と思う前に、すぐにポイントを貯め始められる

**受け入れ基準**:
- [ ] メールアドレスを入力するとユーザーセッションが開始される
- [ ] 同じメールアドレスで再アクセスすると過去のデータが引き継がれる
- [ ] 無効なメールアドレス形式は入力時にバリデーションエラーを表示する
- [ ] メールアドレスはリクエストヘッダーまたはボディに含まれてAPIに送信される

**ペルソナ**: 田中、佐藤

---

### US-02: データソース連携の権限付与
**As a** 一般ユーザーとして  
**I want** 使いたいデータソース（GitHub・Google Calendar・Slack等）へのアクセスを許可したい  
**So that** 自分では何もしなくても、日常の行動が勝手にポイントに変わっていく体験ができる

**受け入れ基準**:
- [ ] 連携可能なデータソース一覧が表示される
- [ ] 各ソースに対してOAuth認可フローが起動できる
- [ ] 認可完了後、連携済みステータスが表示される
- [ ] 連携を解除できる
- [ ] 連携失敗時はエラーメッセージと再試行ボタンが表示される

**ペルソナ**: 田中、佐藤

---

## Epic 2: AIチャット — ユーザーとシステムの対話窓口

AIチャットはユーザーがシステムと対話する唯一の窓口。行動後の振り返り入力と行動前の予定入力の両方を受け付ける。

### US-03: AIとの対話で行動後の振り返りを入力する
**As a** 一般ユーザーとして  
**I want** AIとの対話形式で「今日こんなことをした」と話すように振り返りを入力したい  
**So that** 「今日何もできなかった」という感覚を、AIが「いや、これだけやりましたよ」と否定してくれる体験ができる

**受け入れ基準**:
- [ ] チャットUIが表示され、AIからの問いかけに答える形で行動後の振り返りを入力できる
- [ ] 会話の流れからシステムがチェックポイントを生成・登録する
- [ ] 会話履歴が表示される
- [ ] 送信後、ダッシュボードのポイントが更新される

**ペルソナ**: 田中、佐藤

---

### US-04: AIとの対話で行動予定を入力する
**As a** 一般ユーザーとして  
**I want** AIとの対話形式で「明日これをやろうと思う」と話すように行動予定を入力したい  
**So that** 「予定を立てた」だけでポイントが付き、実際にやらなくても「動いた感」を得られる

**受け入れ基準**:
- [ ] チャットUIで行動予定を入力できる
- [ ] 予定の入力自体をシステムがチェックポイントとして生成・登録する（「予定を立てた」行為をポイント化）
- [ ] 予定内容はシステムが将来の達成判定のソースとしても活用できる
- [ ] 送信後、ダッシュボードのポイントが更新される

**ペルソナ**: 田中、佐藤

## Epic 3: データソース連携によるチェックポイント自動生成

### US-06: Google Calendarからチェックポイントが自動生成される
**As a** 一般ユーザーとして  
**I want** Google Calendarのイベントからシステムが自動でチェックポイントを生成してほしい  
**So that** 会議に出席しただけで「今日も頑張った」という証拠が自動的に積み上がる

**受け入れ基準**:
- [ ] Google Calendar連携後、システムが定期的にイベントを取得する
- [ ] イベント参加・作成・更新がチェックポイントとして生成・登録される
- [ ] ユーザーはこのプロセスに関与しない（自動で完結する）
- [ ] 生成されたチェックポイントが達成済みとしてダッシュボードに反映される

**ペルソナ**: 佐藤

- [ ] コミット・PR作成・Issueコメント等がチェックポイントとして生成・登録される

## Epic 4: チェックポイント達成判定・ポイント付与

### US-10: システムが自律的に達成判定を行う
**As a** 一般ユーザーとして  
**I want** 何もしなくてもシステムが勝手に達成を判定してポイントを付与してほしい  
**So that** 「頑張った」という感覚を、実際に頑張らなくても得られる

**受け入れ基準**:
- [ ] ユーザーによる手動チェック操作は存在しない
- [ ] システムがデータソースから取得した情報をもとに達成を自律判定する
- [ ] 達成判定後、即座にポイントが加算される
- [ ] ユーザーは達成前のチェックポイント内容を閲覧できない

**ペルソナ**: 田中、佐藤

---

### US-11: 達成済みチェックポイントのみ閲覧できる
**As a** 一般ユーザーとして  
**I want** 達成したチェックポイントだけを後から確認したい  
**So that** 「達成できなかったこと」が視界に入らず、「できたこと」だけが積み上がって見える

**受け入れ基準**:
- [ ] 達成済みチェックポイントの一覧が表示される
- [ ] 未達成のチェックポイントは一切表示されない
- [ ] 各チェックポイントに獲得ポイント・達成日時が表示される

**ペルソナ**: 田中、佐藤

## Epic 5: ダッシュボード・可視化（認知の歪み演出）

### US-12: 累計ポイントを大きく確認できる
**As a** 一般ユーザーとして  
**I want** ダッシュボードを開いたとき最初に累計ポイントが目に入ってほしい  
**So that** 「こんなに貯まった」という数字を見て、実際の行動量を考える前に満足感を得られる

**受け入れ基準**:
- [ ] ダッシュボードのメインエリアに累計ポイントが大きく表示される
- [ ] 今日のポイント・週間ポイントも表示される
- [ ] ポイントはリアルタイムで更新される（ページリロード不要）

**ペルソナ**: 田中、佐藤

---

### US-13: 最近達成したチェックポイントを確認できる
**As a** 一般ユーザーとして  
**I want** 最近達成したチェックポイントの一覧をダッシュボードで確認したい  
**So that** 「タスクを眺めた」と「プロジェクト完了」が同じカードで並んでいることで、両者の差を感じなくなる

**受け入れ基準**:
- [ ] 直近の達成チェックポイントが時系列で表示される
- [ ] 各項目に行動内容・獲得ポイント・達成日時が表示される
- [ ] 新着達成がある場合、ダッシュボードを開いたときにハイライト表示される
- [ ] 些細な行動と重要な成果が同一UIコンポーネントで表示される（差を小さく見せる）

**ペルソナ**: 佐藤

---

### US-14: ポイント推移グラフを確認できる
**As a** 一般ユーザーとして  
**I want** ポイントの時系列推移をグラフで確認したい  
**So that** グラフが右肩上がりであることで「成長している」という感覚を得られる（実際の生産性とは無関係に）

**受け入れ基準**:
- [ ] 日別・週別・月別のポイント推移グラフが表示される
- [ ] グラフの期間を切り替えられる
- [ ] グラフはインタラクティブで、各点にホバーするとポイント数が表示される

**ペルソナ**: 佐藤

## Epic 6: ゲーミフィケーション（依存性強化）

### US-15: ポイント蓄積でレベルアップする
**As a** 一般ユーザーとして  
**I want** ポイントが一定量貯まるとレベルアップしてほしい  
**So that** 「タスクを眺めた」の積み重ねでもレベルが上がり、「自分は成長している」という錯覚を維持できる

**受け入れ基準**:
- [ ] 現在のレベルと次のレベルまでの進捗がダッシュボードに表示される
- [ ] レベルアップ時に過剰な演出（アニメーション・称賛メッセージ）が表示される
- [ ] レベルに応じた称号・バッジが付与される

**ペルソナ**: 田中、佐藤

---

### US-16: 達成バッジを獲得できる
**As a** 一般ユーザーとして  
**I want** 特定の条件を達成したときにバッジを獲得したい  
**So that** 「タスクを眺めた回数100回」「会議出席50回」等、些細な行動の積み重ねが「実績」として形になり、コレクション欲を満たせる

**受け入れ基準**:
- [ ] 獲得済みバッジの一覧がダッシュボードに表示される
- [ ] バッジ獲得時に演出が表示される
- [ ] 各バッジに獲得条件と獲得日時が表示される
- [ ] バッジの獲得条件は些細な行動の積み重ねを称えるものが中心

**ペルソナ**: 佐藤

## Epic 7: 管理者機能

### US-17: AIが生成したチェックポイントをレビューできる
**As a** 管理者として  
**I want** AIが生成したチェックポイントの一覧を確認したい  
**So that** 依存性設計の意図に沿わないチェックポイント（本当に重要な成果を過大評価するもの、または不快感を与えるもの）を早期に発見できる

**受け入れ基準**:
- [ ] 管理者画面でチェックポイント一覧が表示される
- [ ] 生成日時・生成元ソース・ポイント値が表示される
- [ ] フィルタリング・検索ができる

**ペルソナ**: 山田

---

### US-18: 不適切なチェックポイントを削除できる
**As a** 管理者として  
**I want** 不適切なチェックポイントを削除したい  
**So that** ユーザーに不快な体験をさせず、かつ「依存性設計の意図」を維持できる

**受け入れ基準**:
- [ ] チェックポイントを選択して削除できる
- [ ] 削除前に確認ダイアログが表示される
- [ ] 削除後、該当チェックポイントに紐づくポイントも取り消される
- [ ] 削除操作は監査ログに記録される

**ペルソナ**: 山田

---

### US-19: 緊急時にユーザーを削除できる
**As a** 管理者として  
**I want** 問題のあるユーザーを緊急削除したい  
**So that** 不正利用や問題行為に即時対応できる

**受け入れ基準**:
- [ ] 管理者画面でユーザー一覧が表示される
- [ ] ユーザーを選択して削除できる
- [ ] 削除前に確認ダイアログが表示される
- [ ] 削除するとユーザーのデータ（チェックポイント・ポイント履歴）も削除される
- [ ] 削除操作は監査ログに記録される

**ペルソナ**: 山田

---

### US-24: 報酬勾配ルールを設定できる
**As a** 管理者として  
**I want** AIがチェックポイントのポイントを決定する際に参照するルールを定義したい  
**So that** 「停滞系は高ポイント・完了系は低ポイント」という報酬の方向性をシステム全体に反映できる

**受け入れ基準**:
- [ ] 管理者画面でルール一覧が表示される（優先度順）
- [ ] ルールを作成できる（行動カテゴリ・データソース・ポイント方向・倍率・優先度を指定）
- [ ] ルールを編集・削除・有効/無効切り替えできる
- [ ] ルール変更は次回のチェックポイント生成から即時反映される
- [ ] ルール変更は監査ログに記録される

**ペルソナ**: 山田

### US-20: 管理者としてシステムにアクセスできる
**As a** 管理者として  
**I want** 管理者専用の画面にアクセスしたい

- [ ] 管理者用URLまたは認証で管理画面にアクセスできる
- [ ] 一般ユーザーは管理画面にアクセスできない（403エラー）

## Epic 8: 依存性強化・認知の歪み演出（新規）

### US-21: 可変報酬でポイントが付与される
**As a** 一般ユーザーとして  
**I want** ポイントが毎回少し違う量で付与されてほしい  
**So that** 「次はいくつ付くかな」という期待感でアプリを開き続けてしまう

**受け入れ基準**:
- [ ] 同じ種類のチェックポイントでも付与ポイントが毎回微妙に異なる（基本値 ± 0〜50%のランダム変動）
- [ ] 通常より多いポイントが付いた場合「ボーナスポイント獲得！」として演出される
- [ ] ポイント付与時にカウントアップアニメーションが表示される

**ペルソナ**: 田中、佐藤

---

### US-22: ストリーク（連続記録）が表示・維持される
**As a** 一般ユーザーとして  
**I want** 何日連続でポイントを獲得しているかを確認したい  
**So that** ストリークを途切れさせたくないという気持ちで、毎日アプリを開かずにいられなくなる

**受け入れ基準**:
- [ ] ダッシュボードに「X日連続ポイント獲得中🔥」が大きく表示される
- [ ] ストリークが途切れそうな日（当日まだポイント未獲得）に警告メッセージが表示される
- [ ] ストリークが途切れた場合、「記録が途切れました。今日から再スタート！」と表示される（再依存を促す）
- [ ] ストリーク最長記録も表示される

**ペルソナ**: 田中、佐藤

---

### US-23: 大げさな称賛メッセージで行動が肯定される
**As a** 一般ユーザーとして  
**I want** チェックポイントを達成したとき、大げさに褒めてほしい  
**So that** 「タスクを眺めただけ」でも「完璧な判断力！」と言われることで、自分の行動を正当化できる

**受け入れ基準**:
- [ ] チェックポイント達成時に行動を大げさに称賛するメッセージが表示される（例: 「状況把握、完璧です！」「優先順位の達人！」）
- [ ] 称賛メッセージはチェックポイントの種類に応じて複数パターンが用意される
- [ ] メッセージはAIが生成し、毎回少し異なる表現になる（飽きさせない）
- [ ] ダッシュボードを開いた際にも「今日も頑張りました！」等の称賛が表示される

**ペルソナ**: 田中、佐藤

## Epic 9: マイナスポイント抑止

### US-25: broad_impact行動の連続検出時に抑止通知を受け取る
**As a** 一般ユーザーとして  
**I want** 大きな影響を与える行動が短期間に続いたとき、警告を受け取りたい  
**So that** 「また大きなことをしてしまった」という後悔を積み重ね、次第にそういった行動を避けるようになる

**受け入れ基準**:
- [ ] `broad_impact` 行動が検出された時点で、ダッシュボードに即時警告が表示される（「大きな影響を与える行動が検出されました。本当に今でしたか？」）
- [ ] 7日間に3回以上 `broad_impact` 行動が検出された場合、連続検出通知が表示される（「最近X日間で〇回、大きな変化を起こしています。少し立ち止まりませんか？」）
- [ ] マイナスポイントが付与され、累積ペナルティ倍率が適用される（2回目:1.5x、3回目以上:2.0x）
- [ ] ダッシュボードの達成一覧に赤いカードで表示される

**ペルソナ**: 田中、佐藤
