# ペルソナ定義

## Persona 1: エンジニア系ユーザー「開発者 田中」

| 項目 | 内容 |
|---|---|
| 名前 | 田中 蓮（28歳） |
| 職業 | ソフトウェアエンジニア |
| 技術レベル | 高（GitHub・Slack・Google Calendar を日常的に使用） |
| 主な行動ソース | GitHub（コミット・PR・Issue）、Slack（メッセージ・リアクション）、Google Calendar（会議） |
| モチベーション | 些細な行動にもポイントが付くことで、「今日何もできなかった」という感覚を持たせないようにしたい |
| 行動パターン | 1日中PCに向かい、コードを書いたり調査したり会議に出たりを繰り返す。大きな成果より小さな積み重ねが多い |
| ペインポイント | 「今日何もできなかった」と感じることが多い。タスクを眺めただけでも何かしたという感覚が欲しい |
| 期待する体験 | ダッシュボードを開いたら、自分が意識していなかった些細な行動にもポイントが付いており、「行動の少なさ」を気にしなくなっている |

**関連ストーリー**: US-01, US-02, US-03, US-07, US-08, US-09, US-10, US-11, US-12

## Persona 2: ライフスタイル系ユーザー「フリーランス 佐藤」

| 項目 | 内容 |
|---|---|
| 名前 | 佐藤 みく（34歳） |
| 職業 | フリーランスデザイナー |
| 技術レベル | 中（Google Calendar・Slack は使用。GitHub は使わない） |
| 主な行動ソース | Google Calendar（クライアントミーティング・作業ブロック）、Slack（クライアントとのやり取り）、テキスト入力（日々の行動メモ） |
| モチベーション | 些細な行動にもポイントが付くことで、「今日あまり動けなかった」という感覚を持たせないようにしたい。難しい設定なしに使いたい |
| 行動パターン | 在宅で作業。カレンダーでスケジュール管理。Slackでクライアント対応。合間に雑多な作業をこなす |
| ペインポイント | 成果物が見えにくい仕事が多く、「今日何した？」と聞かれると答えにくい |
| 期待する体験 | 「Slackで返信した」「ミーティングに出た」だけでポイントが付いており、行動量の少なさを意識せずに済む |

**関連ストーリー**: US-01, US-02, US-05, US-06, US-07, US-13, US-14, US-15, US-16

## Persona 3: 管理者「システム管理者 山田」

| 項目 | 内容 |
|---|---|
| 名前 | 山田 健（40歳） |
| 職業 | システム管理者（本アプリの運営担当） |
| 技術レベル | 高 |
| 主な操作 | AIが生成したチェックポイントのレビュー・不適切なものの削除・緊急時のユーザー削除 |
| モチベーション | ユーザーに不快な体験をさせないよう、不適切なチェックポイントを速やかに除去したい |
| 行動パターン | 定期的にAI生成チェックポイントをレビュー。問題報告があれば即時対応 |
| ペインポイント | AIが不適切・無関係なチェックポイントを生成する可能性がある |
| 期待する体験 | シンプルな管理画面で素早くレビュー・削除できる |

**関連ストーリー**: US-17, US-18, US-19, US-20
